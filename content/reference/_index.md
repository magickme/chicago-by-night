Chicago Chronicles runs on a three-engine hybrid stack. Each system handles a distinct layer of the game.

| Engine | Role | Source |
|--------|------|--------|
| **Vampire: The Masquerade 20th Anniversary (V20)** | Character mechanics, blood economy, Disciplines, Humanity, combat | White Wolf / Onyx Path |
| **Mythic GME 2E** | Solo oracle, Fate Chart, Chaos Factor, Random Events, scene testing | Word Mill Games |
| **Tourniquet / The Scale** | Narrative momentum, story burns, tension escalation | Bully Pulpit Games |

## How the engines interact

Every roll goes through three layers simultaneously:

1. **V20 dice** determine mechanical outcome — successes, failures, botches, extended action progress.
2. **The Scale** reads those same dice for momentum delta. Die faces 1–3 and 8–10 shift Scale; 4–7 are neutral.
3. **Fate Chart** answers uncertain questions about what happens next, filtered through the current Chaos Factor.

These systems reinforce each other. A V20 social roll that crests a Scale **Trouble Burn** forces a Fate Chart call on whether the NPC escalates — and the chaos of that outcome feeds back into CF adjustment at scene end.

## Scope

This reference documents the campaign-specific implementation of these systems — the exact dice pools, table values, ruling glosses, and procedure shortcuts developed across the Chicago Chronicles run. Where this document diverges from published rules, this document governs.
