This reference covers the full rules set for **Vampire: The Masquerade 20th Anniversary Edition (V20)**, including Disciplines, clans, bloodlines, Paths of Enlightenment, combat, feeding, and Kindred society. A separate section covers the solo play engine used to run the game without a Storyteller.

| Section | Contents |
|---------|----------|
| **Character Creation** | Five-step creation procedure, Attributes, Abilities, Backgrounds, Merits & Flaws, Clans, Bloodlines |
| **V20 Mechanics** | Core dice, blood economy, virtues, frenzy, combat, health, hunting, humanity, paths, derangements |
| **Disciplines** | All 17 Disciplines with full power listings, plus Combination Disciplines |
| **Society** | Camarilla, Sabbat, Anarch Movement, diablerie |
| **Solo Engine** | Mythic GME 2E oracle (Fate Chart, Chaos Factor, Random Events) and Tourniquet Scale |
